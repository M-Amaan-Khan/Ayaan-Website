# Mohammad Ayaan Khan - Resume Website

HTML/CSS coursework project for IIM Bangalore BBA DBE. Roll number: **26120793**.

The design returns to the original cream-and-green palette, with Georgia headings, readable system body text and the supplied portrait. The content covers education, school leadership, reported achievements, skills and ongoing study. Career interests are presented as aspirations.

## Preview

Open `index.html` in a browser. Keep `styles.css` and `assets/ayaan-khan.jpeg` in their current locations. The website needs no JavaScript, build tools or external fonts.

## CSS techniques

- Element selectors define body text, headings and links.
- Reusable class selectors define components, widths and spacing.
- ID selectors style unique sections and connect navigation anchors.
- CSS custom properties hold repeated colours, typography and spacing values.
- Flexbox aligns navigation, student details and actions.
- Grid aligns the introduction, education rows, skills and selected sections.
- The desktop/tablet header uses sticky positioning with anchor offsets. The mobile header remains in normal flow.
- Media queries adapt the layout at `60rem` and `40rem`.
- Visible focus outlines, a skip link and reduced-motion support help keyboard users.
- Print rules use a light, readable layout.

## Student details and assets

The website displays the student's full name, roll number and programme. The portrait is the separately supplied photograph. The ID card scan, its photograph, QR code, medical details and date information are not included.
